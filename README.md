# 薪火笔记社非课程共享资料仓

本仓库由 [HIT-Fireworks 课程注册表 v2](https://github.com/HIT-Fireworks/fireworks-course-registry-v2) 统一维护身份与索引。

## 维护约定

- GitHub description 按稳定顺序展示尽可能多的完整代码→原始课程名条目。
- 超过 350 字时以“尚余 N 项”明确标记截断；不得在代码或课程名中间硬截断。
- 完整课程映射始终以本 README 与 Registry 为准。
- 文件库存、容量和内容分类属于 Registry 或审计索引，不写入 description。
- 普通内容增删不应触发 description 更新；课程代码成员或原始课程名变化时才更新。
- 仓库是唯一资源归属边界，需要独立维护的资料通过拆仓表达，不建立仓内资源组。
- 普通独立资料直接放在仓库根目录；软件包、代码项目与多文件文档保留使用所必需的内部结构。
- 课程与文件直接归属仓库，共仓本身不产生资料共享关系。
